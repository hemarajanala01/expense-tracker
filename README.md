# Expense Tracker

A web-based expense tracking application built using Python Flask, HTML, CSS, JavaScript, and Chart.js.

## Features

- Add available balance
- Record expenses
- Categorize expenses
- Edit expenses
- View total spending
- View current balance
- View category-wise spending through a doughnut chart
- Reset expense data

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Chart.js
